How this surfaces in the app (for cross-referencing code)

Once the file is exported, it will just be picked up on the next ingest pass (manual "Ingest now" or the next watched-folder poll, gui.py::_poll_tick / App.POLL_INTERVAL_MS) - no app-side action is needed once the CSV exists. The red "N missing CSV export" indicator (App.load_pending_errors_label, App._last_missing_export) and the Folder sub-tab's banner (App.missing_export_label, wired in load_data_panel.py) clear automatically the next time ingest() reports missing_export == 0.
